# Module 1 Assignment — JavaScript Warm-Up

## Running the project

Open a terminal in this folder and run:

```
npm install
npm start
```

Open the URL that prints in the terminal, then open your browser's
developer console (Cmd+Option+J on Mac, Ctrl+Shift+J on Windows).
Your output appears there. The page itself is intentionally almost blank —
this assignment has no user interface.

Every time you save a file, refresh the browser to see the new output.

## Where you work

| File               | What you do there                                          |
| ------------------ | ---------------------------------------------------------- |
| `assets/data.js`   | Replace the sample books with at least five of your own     |
| `assets/utils.js`  | Fill in the six function bodies                             |
| `assets/main.js`   | Print the seven report sections                             |
| `index.html`       | Nothing. Leave it as is.                                    |

The `import` and `export` lines are already written for you. You are not
responsible for that syntax this week.

## Before you submit

- [ ] At least five books in `data.js`, samples removed
- [ ] All six functions in `utils.js` return a value
- [ ] No `var` anywhere
- [ ] No `.push()`, and no assignments like `book.finished = true`
- [ ] Console output has all seven sections and no red errors
